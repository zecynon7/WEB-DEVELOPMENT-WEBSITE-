# Café BLK & BRWN – Static Website (CC 312)

Open `index.html` in a browser. No installs needed.

```
index, about, menu, branches, reserve, gallery, contact .html   public pages
staff.html                                                      staff demo (not in the menu)
css/   style.css imports base, layout, header, buttons, cards, forms, gallery, menu, staff, footer, responsive
js/    main.js (phone menu + footer year), menu.js, branches.js, reserve.js, contact.js, gallery.js, staff.js
assets/
  logo.jpg, hero_image.jpg
  Branches/        one photo per branch   -> branches page, gallery
  Kape Series/ Chai Blend/ Choco Series/ Over - Ice Series/
  Freskaro Juices/ Hot Beverages/ Food & Snacks/   -> menu page (one card per photo)
  Gallery/         gallery1-8.jpg         -> gallery page, home preview
```

Adding a menu item: put the photo in its category folder, then copy one `<div class="card">` in `menu.html`.
Staff demo login: staff@cafeblkbrwn.com / brwn2026
Content rules (name, PHP format, captions, messages): see `CONTENT-ericka.md`.
